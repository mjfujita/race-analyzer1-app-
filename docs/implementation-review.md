# Race Condition Analyzer v0.4 実装確認書

2026-11-15。ブランチ `feat/market-value-workflow`。今回の依頼で本番反映まで承認済み。実際のリリース先・検証結果は `docs/production-release.md` に記録する。

## 利用の流れ

1. 「自動取得・学習」でPCワーカーの状態と取得済みレースを確認する。既存DBにないレースも、正式な出走馬が取得できれば開ける。
2. 「能力・適性」で馬番、IDM、距離・会場・コース実績、取得時点の単勝を並べ替える。
3. 「展開・天候」で脚質構成、芝・ダート別の当日結果、天候・馬場・パドックを確認する。モデルへ適用した項目と、参考表示だけの情報を区別する。
4. 「市場評価差」で能力pF、条件反映pContext、市場校正pM、統合p*、市場支持率q、価格の変化、最終単勝の予測幅を比較する。
5. 「最終予想・記録」で予算上限・配分方針・価格感度を決める。ACE原案を先に出し、利用者が選んだ軸を含む案と比較する。
6. 予想を固定保存する。実購入と払戻は別に保存し、訂正は理由付きの追記とする。本人用クラウドへ同期し、通信失敗時はローカル記録を保持して再送する。

各レースの「JRDBへ最新取得を依頼」はPCワーカーに取得を依頼する。「保存済みデータと同期」はクラウドにある取得済み情報を読み直す。オッズは最新を自動表示でき、過去時点の手動選択もできる。

購入操作は利用者が行う。予算は上限で、条件を満たす買い目がなければ0円の見送りを出す。

## 自動取得と保存

- 専用ChromeプロファイルでJRDB会員画面を読み、単勝履歴、正式枠、パドック指数、馬体重、天候・馬場、確定着順、取得できた通過順、払戻を時刻・出典hash付きで記録する。
- 発走前後の定刻取得と画面からの取得依頼を処理する。締切は10分前。12分前・11分前も先行取得し、締切後のデータを締切前情報に見せない。
- PACI/TYB/HJCの掲載ZIPを確認し、新しいファイルだけ取得する。PACIは元DBのコピー上で処理し、元の未コミット作業やDBを変更しない。
- 本人用APIとprivate Storageで観測、学習モデル、固定予想、購入、精算を保存する。別ユーザー・匿名・任意パス・機密URLを拒否する。
- 予想・購入・精算は個別immutable記録。訂正分岐と同一IDの内容変更を拒否し、途中通信障害は同一記録の再送で復旧する。

PCの起動、ネットワーク、JRDB認証が必要。電源断・スリープ中は取得できない。公開元の変更や認証切れはエラーとして表示する。

## 数学上の扱い

`q=(1/O)/Σ(1/O)` は投票シェアの近似、`pF` は市場価格を混ぜない能力モデル。`log(pF/q)` が評価差であり、その差だけで有利な購入とは判断しない。損益分岐は `1/p*`、試算回収倍率は `p*×O`。表示オッズから控除率を重ねて引かない。

単勝・複勝・枠連・馬連・馬単・ワイド・3連複・3連単は同じ着順分布から確率を計算する。価格が取得できた組合せを比較し、相関を含めた損失確率と期待利益を表示する。100円単位の候補探索であり、全組合せの大域最適を保証しない。WIN5は対象外。

追加モデルの式・学習条件は [モデルの説明](runtime-models.md)。初回の能力基準を固定し、当日条件・市場統合・最終価格を新しい時刻付き観測で再学習する。十分なデータがない項目は未算出にする。学習済みでも収益性の保証ではない。

## 現在のデータ上の制約

- 既存DBでは距離・会場・コースを加えた能力モデルが、未使用179レースのlog lossでIDM単独2.244300から2.195103へ改善。確定市場モデル1.883844を上回る精度や正の回収率は未確認。
- 追加の脚質構成モデルは校正期間で改善せず、係数0を選んだ。時刻付きT10価格の適格学習レースは現在0件。市場校正・最終単勝価格は蓄積条件を満たしてから有効になる。
- 既存DBの `corner_pass_4` は旧データで人気順位が保存されていたため、展開には使わない。画面で確認した通過順だけを使う。
- 組合せ券の直前価格はJRDBの当該画面だけでは揃わない。取得できた複勝下限や手入力価格を比較し、未取得券は比較件数に含めない。基準オッズを実オッズの代わりにしない。
- 手動の価格下落率と学習予測の幅は別。最終価格の学習対象は単勝であり、複勝・ワイドは取得幅の下限を使用する。

## 検証・技術変更

React画面、確率・配分・履歴、クラウドAPI、ローカル取得ワーカー、Python学習処理を追加。既存本番DBのschema migrationなし。新しいprivate bucketとサーバ環境変数を追加した。サービス鍵とJRDB認証はクライアント配信・Gitから除外する。

```bash
npm run lint
npm run typecheck
npm test
npm run test:pipeline
npm run test:e2e
npm run build
```

lintは分析コンポーネント、計算・記録、APIと検証コードを対象。型チェックはJSDoc公開関数と型契約テストで、旧JS全体を型変換したものではない。Chromeで予想→購入→払戻→訂正→再読込、複数タブ競合、空状態・不正入力・破損、390px幅を確認する。実際の本番認証・同期と件数はリリース記録へ記す。

元の作業コピーは保護し、独立クローンで変更した。本番障害時は記録を消さず、Vercelを以前のdeploymentへ戻し、必要なら取得ワーカーを停止する。
