# 当日条件・市場・最終価格のモデル

実装は `src/predictionModel.js`（画面・推論）、`pipeline/prediction.py`（特徴作成・学習）。モデル束 `model.runtime.json` に固定した能力基準と、追加モデルの状態・係数・検証結果を保存する。

## 能力基準と追加モデル

`model.runtime-base.json` に初回の能力モデルを固定する。毎回再学習する `model.conditions.json` は候補として保持し、運用中の基準を無条件に置き換えない。これにより、同じpFを基準に過去の時刻付き観測を蓄積し続けられる。基準モデルの学習終了日以降に行われた対象レースだけを追加モデル学習に使う。

`pF`（能力）→ `pContext`（取得済みの当日条件）→ `pStar`（T10市場との統合）を別々に保持する。市場支持率qと、市場モデルが校正したpMも別の値として表示する。

当日条件は以下の測定特徴を使う。これら自体を勝率へ固定加点せず、正則化した条件付きロジットモデルで係数を学習する。

| 特徴 | 入力と式 |
|---|---|
| 馬場状態 | 対象日より前・同芝ダートの直近5走から、同じ良/稍重/重/不良の `Σ[0.5−(着順−1)/(頭数−1)]/(該当走数+3)` |
| 天候 | 同様に、記録のある同じ天候の過去走を集計。過去LIVE観測をレースIDで結果へ結合する |
| 展開 | JRDB脚質を前方度に置き、全頭の逃げ・先行比率との組合せを測る。展開シナリオの的中確率そのものではない |
| 当日傾向 | 同日・同場・同芝ダートの先行レースで、勝者の事前脚質と能力確率から期待される脚質との差を集計。`Σ差/(レース数+3)`を今回の脚質へ掛ける |
| パドック | 正式全頭のパドック指数を同一観測内で標準化し、±3に制限する |

当日結果の4角順位は画面から取得した実順位を記述集計に使う。既存DBの `corner_pass_4` は旧データで人気を保存しているため、4角順位としては使用しない。

未知はnullとして保留する。馬場未経験は0への縮約であり、不得意と決めつけない。天候未記録は0の実測値にしない。馬体重・増減は観測表示するが、未検証の方向性で加点しない。

## 取得時刻

公開・観測・取得の各時刻がある場合は、その順序と発走10分前以前であることを確認する。画面を実際に取得した時刻で存在を確認できたデータは、`timingEvidence: observed-visible-at` と `availabilityAt == retrievedAt` を保存できる。公開時刻が不明なままでも、その取得時刻以前から情報が見えていたことを証明する扱いであり、公開時刻を生成するものではない。

後日取り込んだ過去ZIPに上記の証拠を付けない。締切後の訂正は、締切前の観測を置き換えない。学習済みモデルも学習終了日・生成時刻・採用時刻・能力基準IDを確認してから適用する。

## 市場と最終価格

全頭のT10観測を使い、`pM ∝ q^γ`、`pStar ∝ pContext^α × pM^(1−α)`を学習する。確定オッズからT10観測を作らない。能力と市場は同じ全頭集合で正規化する。

最終単勝価格は、`log(最終倍率/観測倍率)`を以下の特徴から回帰する。

- 切片、観測倍率の対数
- 前回からの対数変化を経過分数で割った値（10分換算）
- 発走までの残り時間、前回観測の有無

校正期間の残差中央値で点予測を調整し、残差10/90%点で中央80%の予測幅を作る。これは払戻価格の予測幅であり、期待利益の統計的下限ではない。最終単勝以外の券種は、取得した実オッズと明示的な価格感度で比較する。

## 学習と採用

60レース・15日を処理上の最低値とし、日付順に約60/20/20%へ分ける。追加条件は訓練期間で30レース以上観測でき、値に変化がある項目から学習する。この件数は精度や利益の保証ではない。

条件係数は訓練期間で当てはめ、正則化と追加採否を校正期間だけで選ぶ。γは訓練期間、αは校正期間で選択する。最終価格も訓練・校正だけで係数と残差幅を決める。未使用期間の結果は報告のみに使い、そこでモデルを選び直さない。

T10観測が不足する間は、既存KYIの脚質構成だけを使った研究用の追加モデルを比較できる。2026-11-15の実DB検証では、この追加係数は校正期間で改善せず0を採用した。天候・パドック・当日傾向、市場統合、最終価格について係数を捏造しない。`insufficient-data`は機能がない状態ではなく、必要な時刻付き教師データが揃うまで推定を保留している状態。

実DBでは固定能力モデルの学習終了日より後に179レースがあり、日付で分割した。校正期間のlog lossは基準 `1.9225819568`、展開特徴の追加候補 `1.9227913998` で、後者の方が小さくならなかったため係数0を選んだ。未使用評価は11レースで、基準・選択モデルとも `1.8745338536`。この少ない未使用件数から収益性・汎化精度を保証しない。時刻付きT10価格の適格学習レースは0件だったため、市場統合と最終価格の係数は未学習として出力した。

元DBに全頭の出走時IDMがある新レースは、巡回後の単独勝者結果から学習ラベルを作れる。未掲載の下位着順は生成しない。最終価格は、明示的な最終オッズ表示または元DBの確定単勝オッズがある場合だけ教師ラベルとして利用する。
