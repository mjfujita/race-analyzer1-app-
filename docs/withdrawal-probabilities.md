# 取消後の確率表示の復旧（2026-11-28）

京都11Rは、PACI由来の画面用頭数が11頭のまま、同期した出走情報は9番取消・実出走10頭だった。登録処理はPR #36で取消を除く10頭へ対応したが、能力確率の全頭照合が11対10として不一致となり、全馬・全グループの確率が保留になっていた。

`buildAbilityField`の頭数照合を修正する。取消前の正式頭数と取得リストの全頭数が一致し、全馬番が正しい範囲の重複なしで、明示的な取消情報がある場合のみ、取消を除いた頭数を期待値とする。明示された`activeFieldSize`は優先し、不一致を握り潰さない。単なる馬の欠落や重複、正式頭数不明、IDM不足は引き続き保留する。新馬・過去走不足の保留、締切・モデル時点の制限は維持する。

確率モデルの係数・校正・算式を変更するものではない。取消対象を除外した既存計算に正しい出走頭数を渡す。保存済みグループ・登録時確率・予想・結果を書き換えず、過去の保留値を現在の値で埋めない。登録時確率を新しく保存する場合は、その時点の明示的な更新を使う。

実データの読取再現で、11頭指定の旧条件は全頭保留、修正後は取消を除く10頭・720通りの着順と全グループの確率が計算できることを確認。架空データで各着順確率の合計1、取消馬の不在、明示的な実出走頭数で計算した場合との完全一致、欠落・重複・競合する頭数の保留を検証する。ブラウザーでは群・各馬の表示と登録時確率保存を確認する。

同じ障害の修正として先の本番反映依頼を継続する。API/DB schema/migration/認証/取得ワーカーの変更なし。反映結果・検証数・復旧先は当該PRに記録する。
