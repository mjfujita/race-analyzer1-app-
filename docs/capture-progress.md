# 最新取得の状態と観測時点

- 「JRDBへ最新取得を依頼」はMacワーカーへの依頼。受付だけを取得完了と表示しない。
- 本人限定GET `/api/companion?capture=1&raceId=...&raceDate=...` は当該レースの最新依頼の pending/completed/failed/expired とワーカー最終連絡時刻を返す。登録・認証・TTL・不変の完了記録は既存方式を維持する。
- 画面は10秒ごとと画面復帰時に確認する。completedはワーカーが取得・本番同期後に残した完了記録で確認し、保存済みデータを画面へ再同期する。失敗・5分の期限切れ・API接続失敗は個別表示する。
- 取得依頼/状態確認は15秒、観測データGETは20秒で打ち切り、保存済み記録を保持して再試行できる。
- 観測時点はJRDBのオッズ時刻、取得時刻は実際に取得した日時。再取得で元の公開・取得時刻を捏造しない。同一オッズ時刻や発走後の確定価格では観測時点が進まない場合がある。
- 最新表示では新しい観測の同期後に自動追従する。明示的に過去を選択した場合は保持し、「最新の観測を表示」で戻せる。保存済みグループ判断・予想・購入台帳は上書きしない。
- 発走後の確定価格は従来どおり事前観測へ変換しない。後から取得した過去オッズは取得時刻を維持し、締切前の予測証拠としない。
- DB/migration/環境変数/本人認証の変更なし。APIは読み取り機能の追加のみ。既存collectorは変更不要。
