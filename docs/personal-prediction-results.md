# 私の予想：保存した組み立てと結果

## 表示

- 私の予想ページの先頭に保存記録を表示する。保存が複数ある場合は切替可能。
- 券種・買い方・点数・予定金額、保存した群の組み立て、実際の結果を比較する。
- 各着順の候補馬番、結果の群・馬番・馬名、一致/不一致/除外馬を表示する。
- 結果は保存時の分類で照合する。新しいオッズ・手動区切り・候補除外の変更で保存案を書き換えない。
- 2/3着入替案は実際に採用した着順、馬単は上位2頭で比較。3連複は着順不問で馬番の組合せを照合する。
- 予定額0円で除いた買い目を的中にしない。予想の的中と実購入・精算の収支は分ける。
- 結果未取得は結果待ち。同着・取消・不完全/競合する結果は照合保留。モデル検証レポートが結果待ちでも、新たな検証可能な公式画面結果を照合できる。

## データと影響

既存のimmutable groupPlans、snapshot、grouping、slots、excluded、allocations、LIVE_RACE/HJC結果を使用する。DB/schema/API/認証変更はない。過去の保存案を新形式へ書き換えずに表示する。

今回の実装は本番未反映。既存の取込ワーカー・本番データに変更はない。
