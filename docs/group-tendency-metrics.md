# グループ傾向の実績率・頭数・ACE比較

本番反映対象：当日の全レース・グループ傾向。グループ登録、予想、購入、結果の既存レコードは変更しない。

## 表示と分母

- 群／平均頭数／1着・2着・3着の回数と実績率を表示する。実績率は、条件で絞った結果照合可能な同じNレースが分母。群が存在しないレースの実績は0なので、各着順の全群の率の合計は100%。
- 平均頭数と平均占有率は、その群が存在したレースのみで計算する。占有率は各レースの「群の頭数／全出走頭数」を平均する。存在したレース数とNも表示する。
- 結果待ち・分類待ち・同着等の保留は分母から除く。0レースの割合を0%やNaNと表示しない。
- 競馬場・芝／ダート等・新馬／未勝利等で絞り込み、実績・ACE比較・組み合わせを同じ対象で更新する。不明な条件は情報未取得として扱う。
- 着順ありの1・2着パターンと1〜3着パターンを、回数・N・実績率の順で表示。同じ群が複数着に入っても着順を維持し、1レース1パターンとして数える。

## ACE想定回数との比較

既存の独立グループ登録またはselection予想に残る、実際に事前保存された群の1着／2着／3着確率だけを使う。今のモデルで過去レースを再計算しない。

比較条件：

1. 同じレース・日付で、群の所属と全出走馬が結果の分類と一致する。
2. 記録日時・確率の参照時点・観測取得が発走前で、時刻の前後関係が正しい。
3. 発走前のクラウド受付時刻がある。事後同期・ローカルだけの記録は対象外。
4. 全群について各着順確率が0〜1、各着順の全群合計が1、群の頭数と全出走頭数が記録と一致。候補除外で一部だけになった確率や保留を0として補完しない。

同じ条件を満たすレース集合Cに対し、各群の各着順確率を合計した想定回数と、そのC内の実績回数・差を表示する。通常の全レース実績の分母と混ぜない。比較可能件数／全体件数と、対象外の理由を表示する。結果より後の記録や分類変更後の確率を事前予測に見せない。

複数記録があるレースは、条件を満たす最後の事前記録を一度だけ採用する。モデル試算に対する記述的な比較で、差を次レースの有利さや回収率と解釈しない。
