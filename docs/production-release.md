1. 「自動取得・学習」で36レースの取込状況、最終稼働、データ送信成功時刻、学習状態を確認する。

## データとモデルの制約

- 市場校正と最終単勝予測は、適格なT10観測がまだ0レースのため未算出。最低60レース・15開催日と時系列分割の条件を満たして評価する。単に実装しただけで学習済みとは表示しない。
- 天候・展開・パドックの学習処理と根拠表示を実装したが、現状の追加モデルは脚質構成のみ、校正で改善せず係数0。情報が揃わない条件を固定点で加算しない。
- 馬連等の組合せ現在価格は、確認したJRDB入口の接続制約で自動取得できない。実価格を入力した券種だけを比較し、基準価格や確定払戻で購入時価格を代用しない。
- 当日傾向には取得時刻が確認できる結果を使う。旧DBで人気が入っていた4角欄は通過順位として使わない。
- 確率・回収率は研究用試算。実績で正の回収率を確認したものではなく、全買い目の大域最適も保証しない。
- PCの起動・ネットワーク・JRDB認証が必要。電源断・スリープ中は取得しない。異常は画面に表示し、同一データを再送できる。
