# レース結果と予想の比較

## 画面と導線

- PC／スマホの開催メニューを「本日のレース・予想と結果・振り返り・データ管理」に整理（画面ラベルは「予想・結果」）。
- レース内の「軸候補」タブを外し、同じ位置に「予想・結果」を置く。新しい軸候補を選ぶ画面への通常導線を外す。
- 本日のレース一覧からレースを開くと結果比較へ、次に予想するレースの「グループを確認」からはグループ編集へ進む。
- 予想・結果には、選択レースの保存した組み立てと実際のグループ・馬番を隣同士で表示する。スマホでも比較の2列を維持する。
- 当日の一覧は開催レース単位で表示し、保存予想のないレースを「予想未登録」、着順のないレースを「結果待ち」として残す。各行からそのレースの比較画面へ移動できる。
- 各行で予想した群／候補馬番・頭数／結果の群・馬番／買い目点数・対象頭数／買い目への包含／100円あたり確定払戻を確認できる。
- 複数の予想は一覧では最後の保存案を採用する。選択レースの保存記録切替で、以前の案も確認できる。

## データの扱い

既存のgroupPlansとselection journalを利用する。保存時の分類・馬番・確率を変えずに結果と照合する。結果のみ存在する場合に予想やグループを作ったことにしない。手入力とJRDBの競合、異常結果は照合保留を維持する。群別回数はレース単位で1回だけ数える。

旧軸候補の予想・購入・精算データは削除しない。従来の記録は「振り返り」から開ける。能力の計算・ACEモデル・取込ワーカー・認証と権限は変更しない。

本人限定journal GETに、予想の有無に関わらない当日開催情報 `races` を追加する。既存レスポンスのフィールドは維持する。DB schema / migration / データ変換・削除なし。
