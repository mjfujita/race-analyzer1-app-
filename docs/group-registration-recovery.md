# グループ登録ボタンの復旧改善（2026-11-28）

## 確認した不具合

登録履歴の再同期で状態を初期化し、`journal.loading`、レース全体の同期中、`journal.error`のいずれでも登録ボタンを無効化していた。そのため、全頭の観測と登録履歴を既に確認済みでも、背景同期の遅延中は押せず、取得失敗後も無効状態が残った。架空データの認証API・保存ストアを使うE2Eで、旧コードのボタンがdisabledになることを再現した。

本番で読取確認した登録13件は検証を通過し、取得したランタイムログ50件はHTTP200だった。利用者端末そのものはブラウザ接続不可のため未確認であり、この不具合が今回の端末で発生した直接原因とは断定しない。

## 変更

- 初回の登録履歴確認と、確認済み状態からの背景同期を分離する。
- 背景同期で既存の分類や登録状態を空にせず、確認済みの分類から登録を継続できるようにする。
- 一時的な同期失敗・保存失敗後も設定と再送IDを保持し、そのまま再試行できる。
- 初回の登録状態未確認、破損データ、全頭オッズ不足、取消、保存処理中は引き続き保留し、理由を表示する。
- 同じ分類は「グループ登録済み」と表示し、区切り・観測変更で更新可能なことを伝える。
- 遅い過去リクエストで新しい読み込み状態を上書きしない。

API、DB schema、登録内容の形式、認証、ワーカー、確率計算は変更しない。サーバーの全頭照合、更新元ID、端末間競合、同じIDの再送チェックを維持する。実データの削除・書き換えは行っていない。

## 検証・反映

ローカルの`market-preview.html?state=groups-local-review`は架空データ専用。実レースや購入に接続しない。背景同期失敗、保存失敗の直接再試行、初回取得失敗と再読込、登録済み表示、スマートフォン幅を関連E2Eで確認する。既存の結果集計・予想保持・端末間競合のテストも維持する。

検証結果：lint、型チェック、ビルド、Node195件成功。全画面E2Eは72/73件成功し、残り1件は初回読込と自動同期の重なりを待たないテストのタイムアウトだった。待機条件を修正後、登録関連6件すべて成功。最終文言の関連6件と、PC/390pxの状態表示も確認済み。全73項目の成功を確認したが、最終の全体一括再実行は行っていない。

確認用URL：`http://localhost:5175/market-preview.html?state=groups-local-review`。ローカル起動中のみ利用可能。
