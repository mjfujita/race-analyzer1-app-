# スマートフォンの当日レース一覧

旧画面は、当日の開催をホーム画面の重いdashboard API応答から追加していた。一覧へ移動するとホームの取得が中断され、スマートフォンに古いPACIが保存されている場合は過去の開催だけが表示された。PCでホーム応答を待って確認するだけでは、この経路を検出できなかった。

本人専用 `GET /api/companion?catalog=1` を追加。当日JSTの開催メタデータだけを取得し、予想・購入台帳・観測・モデルの取得を待たない。従来同様に本人アカウントまたは承認済み端末の認証を必須とし、no-storeを維持する。追加パラメータは拒否する。

一覧は独立した取得処理を持ち、ページ切替で中断しない。起動時、復帰時、60秒周期、再取得ボタンで更新する。15秒で応答がない場合はエラーを表示して再取得できる。初回取得中は日付選択を待機させ、古いPACIだけを現在の全開催として見せない。

同期済み開催と保存済みPACIの日付を合わせ、新しい日を初期選択する。利用者が選んだ過去の日付は更新時も保持する。開催が一覧からなくなった場合は存在する日付へ戻す。表示中のレース数・登録頭数を先に表示し、保存済みPACI全体の集計は開閉欄で維持する。

検証は古いgzip SQLiteのPACIとCookieだけの端末認証を使用する。スマホ幅390pxで、ホーム失敗・当日一覧の遅延・素早い画面移動から当日の24レースを表示し、手動日付保持、詳細を開く、通信失敗からの再取得、未同期の空状態を確認する。架空データのみを使用し、本番の予想・購入記録は作らない。

DB migration、RLS、公開設定、認証方式、collector、確率モデル・採用条件は変更しない。当日データの取込済み原本も維持する。反映は同じVercelプロジェクトの検証済みproduction候補をpromoteし、旧deploymentへのrollbackを保持する。
