# 全頭比較表のグループ表示

「全頭の妙味と人気の推移」の馬名の横にグループを表示する。既存の単勝オッズ間隔 `odds-gap-v1` を利用し、能力や勝率の順位をグループの代用にしない。

- 初期分類は倍率1.5。グループ画面で変更した倍率は同じアプリの利用中に共有する。同じレース・同じ観測IDの場合のみ手動区切りも共有する。
- グループ画面へ戻った際、直前の観測選択と区切り・倍率を復元する。最新への追従は維持し、観測が変わったときに過去の手動区切りを流用しない。
- 別レース・別開催の設定は参照しない。オッズ未取得・不完全では「—」と判定保留を表示する。不整合な区切りは自動分類へ戻し、その旨を表示する。
- 表示用の状態は画面内のみで保持する。新しい保存領域やクラウド書込は追加しない。リロード後は自動分類へ戻る。予想・購入台帳への書込、確率・回収率の計算、DB/API/認証/collectorに変更はない。

検証: 自動分類一致、手動区切り共有、別時点への切替、未取得・不整合、入力の非破壊、確率不変、スマホのはみ出しを確認する。
