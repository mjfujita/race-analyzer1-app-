# 馬ごとの能力・今回の評価

目的は、能力・適性の画面で各馬の近走、今回の条件、パドック・直前情報を根拠付きで確認できるようにすること。今回の到達点はテスト・画面検証・本番反映。既存の本人専用キャッシュ、出走馬・統計・観測だけを使う。DB/API/認証/collector/確率モデルの変更は行わない。モデル再学習・採用・購入・精算は対象外。

## 画面と評価文

全頭のカード、馬番での絞り込み、出走時IDMの同値同順位、取得頭数、取消・欠測状態を表示する。今回の評価文はIDM相対順位と取得済み近走の条件実績から作る説明。勝率・回収率の新しい推定や任意の加点はしない。従来の数値比較・オッズ入力・JSON入出力は維持する。

過去走は当日より前の日付を確認できる直近最大5走。年月だけの旧データはレース月より前のものだけを使う。同日以降・日時不明の走は評価から除外し、除外件数を示す。着順が不正な走を3着内実績に数えない。近い距離は同じ区分の±200m、同場同距離は競馬場・距離・区分が一致する走。生涯成績や未取得の出走を推測しない。新馬・少数例・条件不足は保留を明記する。

直前情報は既存のowner別キャッシュのLIVE_RACEから、同一race ID・開催日・時刻証跡を照合する。既定は現在と発走10分前の早い方まで。オッズ時点を手動選択した場合はその取得時刻も上限とする。馬体重・増減、JRDBパドック点、馬番が一致する取得済みコメントを表示。0点・増減0は欠測と区別し、欠測を良否の評価に置き換えない。取得・公開日時と取得元を表示する。

チェックを外した最新表示は締切後を含む参照用。参照時点を超える場合は明示し、今回の評価文・勝率へは反映しない。現在のcollectorが提供しないコメントは未取得のままにし、生成しない。表示画面で外部AIや新APIへの送信・契約は行わない。

## 検証と運用

NodeでIDM同値・欠測・取消・ゼロ、日付境界、過去5走、区分別集計、オッズ非依存、同一レース照合、締切後と未来情報の除外を確認。Chromeでは長い馬名、絞り込み、過去走内訳、欠測、直前情報の同期、参照切替、390px表示を架空データで確認する。既存の予想・台帳・同期・端末認証の回帰も実行する。

本番の表示確認で必要な場合は既存collectorによる対象レースの現在取得だけを行う。原本・予想・購入履歴は保持し、学習は実行しない。時刻証跡のない数値や新サービスの認証が必要な場合は推測で補わない。戻す場合は直前のVercelデプロイをpromoteし、取込済み観測は残す。

参考: [JRDBのIDM調整値](https://jrdb.com/manual/idm/adjustment)、[JRDB直前情報ヘルプ](https://jrdb.com/n_live/help.html)、[パドック詳細の案内](https://jrdb.com/manual/direct-info/paddock-detail)。
## グループからの馬詳細

グループカード内と全頭比較表の各馬名から、その馬に絞った評価・過去走・パドックを開く。戻るボタンでグループ画面へ戻り、観測選択・区切り・着順候補・予算・根拠・買い目の入力とスクロール位置、押したボタンへのフォーカスを保持する。詳細への移動は判断・購入の保存操作ではない。

表示は既存の各馬評価と同じ処理を利用し、グループで選択していた観測の取得時刻を参照上限として渡す。未取得情報や締切後の参考情報の扱いを維持する。DB・API・認証・collectorの変更なし。

## 展開・馬場からの馬詳細

脚質の配置にある馬番（脚質未取得の一覧を含む）と「出走馬ごとの根拠」の馬名から個別詳細を開く。既存の評価・過去走・パドック表示を再利用する。「展開・馬場へ戻る」で表示条件・補完フォームの入力・元のスクロール位置と押したボタンへのフォーカスを維持する。詳細表示だけで結果や予想を保存しない。時点の制約・予測計算・DB/API/認証/collectorは変更しない。
