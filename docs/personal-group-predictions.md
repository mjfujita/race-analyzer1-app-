# 私の予想：グループで選んだ買い目の登録

レースを選択し、レース内メニューの「私の予想」を開く。「グループ・買い目」の「私の予想を登録」からも開ける。

## 操作

1. グループと対象馬を確認する。手動の区切り・除外馬は同じレースの画面間で引き継ぐ。必要なら「グループを確認・調整する」へ戻る。
2. 「新しい予想を入力する」を押す。入力開始時のレース・単勝観測・グループ・除外馬・能力材料をコピーし、同期で差し替えない。
3. 馬単／3連単／3連複と、フォーメーション／グループBOX／グループ軸ながしを選択する。グループ選択は空欄から始める。
4. グループを指定すると「選択した馬番」に着順別の馬番を表示し、具体的な買い目を自動で開く。除外馬は含めず、同一馬が重なる買い目も除く。BOXは対象全頭、3連複は着順不問の1〜3頭目として表示する。点数・予定金額を確認する。予算上限は10,000円、100円単位。均等配分または買い目別の調整が可能。0円は登録しない。大量の買い目は先頭100点まで表示する。
5. 予想メモを入れ、「私の予想を登録する」を押す。保存後は「私の予想・購入記録」に表示する。実購入は自動作成しない。
6. 購入済みの場合は「この案の実購入・払戻を記録する」を開く。予定額を初期表示するので、実際の買い目・金額へ直して保存する。正式払戻は別途記録する。

軸ながしの軸はグループであり、グループ内の全頭が軸候補。3連複はそのグループから少なくとも1頭を含む組み合わせ。馬単・3連単では軸の着順を選べる。BOXは選択グループの全頭を組み合わせ、同一馬の重複・同じ買い目の重複を除く。

## 記録と検証

既存の不変 `groupPlans` 台帳を再利用する。券種、着順別グループ、全構成馬、観測、予算、個別配分は構造化して保存。買い方の名称と選択意図は既存 `note` に保存する。新規API・DB migration・権限変更なし。PACI、取得ワーカー、予測モデルは変更しない。

ブラウザ保存後に既存の本人専用クラウドへ同期。失敗時はローカル記録を保持し、再同期できる。保存済み記録は上書きせず、別の予想は新規登録する。入力中の画面移動・再読込は未保存の入力を破棄する。

既存の結果照合と振り返りに含める。発走10分前を過ぎた登録や時刻証跡が不足する場合は過去検証。締切前のクラウド受領が確認された最後の案だけを正式的中集計に使用。実購入・精算済み収支と予想だけの的中は分離する。同着・異常着順は推測せず正式払戻を照合する。

組合せの現在オッズをこの入力画面では扱わないため、期待回収率・的中確率・想定払戻は算出しない。実購入・精算は実額で記録する。
